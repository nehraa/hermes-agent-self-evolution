# Personal Knowledge Base - 个人知识库

> 收集、整理、可检索的个人知识库

## 功能概述

| 功能 | 说明 |
|------|------|
| 添加 | 存储文章、链接、笔记到知识库 |
| 搜索 | 自然语言查询已存储的知识 |
| 整理 | 按标签分类和排序 |
| 回顾 | 定期查看和更新知识 |

## 存储位置

`memory/knowledge-base.md`

---

## 使用命令

### 添加知识

请把以下内容存入知识库：
- 内容：[URL 或 正文摘要]
- 标题：[自动提取或手动指定]
- 标签：[标签1, 标签2]
- 备注：[可选备注]
**示例：**

请把以下内容存入知识库：
- 内容：https://example.com/article
- 标题：AI 大模型发展历程
- 标签：AI, 技术
- 备注：包含 2024 年最新进展
### 搜索知识

请在知识库中搜索：[你的问题或关键词]
**示例：**

请在知识库中搜索：关于 AI 编程工具的内容
请在知识库中搜索：Python 异步编程技巧
### 列出知识

请列出知识库中的所有内容
请按 [标签] 分类列出知识库
### 整理知识

请整理知识库，合并重复内容
请更新知识库中 [标题] 的标签为 [新标签]

## 最佳实践

1. **保持简洁**：每条记录只记录核心信息，避免大段复制
2. **添加标签**：方便按主题快速检索
3. **及时回顾**：定期查看知识库，更新过时内容
4. **链接优先**：优先保存原始链接，便于追溯
5. **关联知识**：新知识入库时，思考是否与已有知识相关

# Personal Knowledge Base - 个人知识库

> 收集、整理、可检索的个人知识库

## 功能

| 功能 | 说明 |
|------|------|
| **添加知识** | 将文章、链接、笔记存入知识库，支持自动打标签 |
| **搜索知识** | 支持自然语言语义搜索，快速定位相关内容 |
| **整理知识** | 自动分类、合并重复内容、更新过期信息 |
| **回顾知识** | 定期提醒回顾遗忘的知识点 |

## 使用方式

### 添加知识

请把以下内容存入知识库：
内容：[URL 或 文本内容]
标签：[可选标签，多个用逗号分隔]
摘要：[一句话概括核心内容]
**示例：**
请把以下内容存入知识库：
内容：https://example.com/article-about-rag
标签：AI, RAG, 技术
摘要：RAG技术详解及其在LLM中的应用
### 搜索知识

请搜索知识库：[查询内容]
**示例：**
请搜索知识库：关于 RAG 优化的最新方法
### 列出知识

请列出知识库：[筛选条件]
- `请列出知识库：所有内容` - 列出全部
- `请列出知识库：标签=AI` - 按标签筛选
- `请列出知识库：最近一周` - 按时间筛选

### 更新知识

请更新知识库：[内容标题]
新内容：[更新后的内容]
### 删除知识

请从知识库删除：[内容标题]
原因：[可选说明]

## 知识入库标准

符合以下条件的内容才应入库：

- [ ] 有明确的知识点或可复用信息
- [ ] 对未来可能有参考价值
- [ ] 包含实际可操作的建议或方法
- [ ] 来源可靠或有验证

**不入库的内容：**
- 纯娱乐或消遣内容
- 一次性使用的临时信息
- 未经核实的未经证实的信息

## 数据源

| 来源类型 | 说明 |
|----------|------|
| **论坛/社区** | 技术论坛讨论中学到的经验 |
| **技术文章** | 博客、文档、教程中的精华 |
| **AI工具** | AI 相关工具的使用技巧和最佳实践 |
| **个人决策** | 重要决策的记录和复盘 |
| **经验总结** | 项目中总结的教训和方法论 |

## 维护建议

1. **每周回顾**：检查新增内容，确保摘要准确
2. **月度整理**：合并重复内容，更新过期信息
3. **季度清理**：删除已过时的内容，整理标签体系
4. **定期搜索**：用不同关键词搜索，验证内容可被找到

# 个人知识库 (Personal Knowledge Base)

> 构建可持续积累、随时可检索的个人知识管理系统

## 核心功能

| 功能 | 说明 |
|------|------|
| **添加** | 存入文章、链接、笔记、想法，支持指定标签 |
| **搜索** | 自然语言查询，快速定位相关知识 |
| **分类** | 按标签分类，支持按时间/主题多维度浏览 |
| **回顾** | 定期回顾，强化记忆，巩固知识 |

## 使用方式

### 添加知识

请把这篇文章存入知识库：[URL 或 内容摘要]
标题：[自动提取或手动指定]
标签：[可选，多个标签用逗号分隔]
**示例：**

请把这篇文章存入知识库：https://example.com/article
标题：如何构建个人知识体系
标签：知识管理, 方法论
### 搜索知识

请搜索知识库：[关键词或问题]
**示例：**

请搜索知识库：关于 AI 编程工具的内容
请搜索知识库：2024 年收藏的工具
### 列出知识

请列出知识库所有内容
请列出标签为 [标签名] 的知识

## 知识来源

- 📖 技术博客 / 论坛 / 社区
- 📰 新闻资讯 / 行业报告
- 🛠️ 工具评测 / 使用技巧
- 💡 个人思考 / 经验总结
- 🎓 课程笔记 / 书籍摘要

## 管理原则

1. **定期整理** - 每周花 15 分钟归类新知识
2. **添加标签** - 每条知识至少一个标签
3. **简短摘要** - 用一句话概括核心内容
4. **及时回顾** - 每月回顾一次知识库
5. **删除冗余** - 清理过时或重复的内容

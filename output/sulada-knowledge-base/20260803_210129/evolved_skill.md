# Personal Knowledge Base - 个人知识库

> 收集、整理、可检索的个人知识库

## 功能概览

| 功能 | 说明 |
|------|------|
| **添加** | 存入文章、链接、笔记到知识库 |
| **搜索** | 用自然语言查询已存储的知识 |
| **分类** | 自动按标签和时间归档 |
| **回顾** | 定期提醒复习遗忘的知识 |

## 使用方式

### 添加知识

请把这篇文章存入知识库：[URL 或 内容]
标签: [可选标签，用逗号分隔]
**示例：**
请把这篇文章存入知识库：https://example.com/article
标签: AI, 工具
### 搜索知识

请搜索知识库：[查询内容]
**示例：**
请搜索知识库：关于 Python 异步编程的资料
### 列出知识

请列出知识库所有内容

## 维护建议

### 记录内容

- **来源**: 论坛帖子、博客文章、教程视频
- **内容**: 技术笔记、工具使用心得、项目经验
- **格式**: 标题 + 链接 + 摘要 + 日期 + 标签

### 标签规范

常用标签示例：

| 标签 | 用途 |
|------|------|
| AI | 人工智能、机器学习相关 |
| 工具 | 开发工具、软件推荐 |
| 前端 | Web 开发相关 |
| 后端 | 服务器、数据库相关 |
| 项目 | 个人项目记录 |
| 决策 | 重要决定及原因 |

### 定期回顾

- **每周**: 检查新增内容，补充遗漏的标签
- **每月**: 回顾上月添加的知识，强化记忆
- **每季**: 整理过时内容，删除失效链接

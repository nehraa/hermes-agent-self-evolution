# Personal Knowledge Base - 个人知识库

> 收集、整理、可检索的个人知识库

## 功能概述

| 功能 | 说明 |
|------|------|
| **添加** | 存入文章、链接、笔记 |
| **搜索** | 自然语言查询 |
| **分类** | 自动标签和分类 |
| **回顾** | 定期复习遗忘内容 |

---

## 使用方式

### 添加知识

请把这篇文章存入知识库：[URL 或 内容]
标签: [可选标签，用逗号分隔]
备注: [可选补充说明]
**示例：**
请把这篇文章存入知识库：https://example.com/article
标签: AI, Python
备注: 关于 Transformer 架构的核心概念
### 搜索知识

请搜索知识库：[查询内容]
**示例：**
请搜索知识库：Python 异步编程
请搜索知识库：所有 AI 相关的笔记
### 列出所有知识

请列出知识库所有内容
请列出知识库：[标签名] 标签下的内容
### 回顾知识

请回顾最近添加的知识
请回顾 [标签名] 相关的知识

---

## 最佳实践

1. **及时记录** — 遇到有价值的内容立即存入，避免遗忘
2. **精简摘要** — 一句话概括核心要点，便于快速回忆
3. **添加标签** — 按主题、技术栈、场景多维度打标签
4. **定期回顾** — 每周回顾一次，强化记忆
5. **关联知识** — 在备注中关联相关笔记，形成知识网络

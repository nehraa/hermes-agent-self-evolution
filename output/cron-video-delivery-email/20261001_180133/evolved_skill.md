# Cron Video Delivery via Email

Use Gmail SMTP to email videos produced by cron jobs instead of pushing them to Telegram at runtime.

## When to Use

| Trigger Phrases | Use Case |
|-----------------|----------|
| "email me the video" | User explicitly requests email delivery |
| "send to my email" | Alternative delivery method specified |
| "rather than sending at the same time" | Deferred delivery preference |
| "deliver later" | Batch delivery instead of real-time |

**Prerequisites:**
- Video file < 25 MB (Gmail hard limit)
- Gmail account configured in `~/.config/himalaya/config.toml`
- Recipient: `abhinavnehra2203@gmail.com`

## When NOT to Use

- **Files > 25 MB** — Gmail attachment limit; use Telegram or cloud storage instead
- **Real-time push required** — Email has inherent latency; Telegram is faster
- **Inline preview needed** — Email clients display as attachment, not inline player

## Implementation

### Function: `send_email()`

Drop-in replacement for any `send_telegram()` function call.

python
def send_email(file_path, subject_context="Video Export", dur_or_size=None):
    """Send a video file as an email attachment via Gmail SMTP.
    
    Args:
        file_path: Path to the video file.
        subject_context: Subject line prefix (e.g., "Meeting Recording").
        dur_or_size: Optional metadata for logging.
    
    Returns:
        bool: True if sent successfully, False otherwise.
    
    Behavior:
        - Auto-compresses via ffmpeg if file > 10 MB.
        - Recipient: abhinavnehra2203@gmail.com
    """
    import smtplib
    import ssl
    import subprocess
    from email.mime.multipart import MIMEMultipart
    from email.mime.base import MIMEBase
    from email.mime.text import MIMEText
    from email.encoders import encode_base64
    from pathlib import Path

    src_path = Path(file_path)
    
    if not src_path.exists():
        print(f"[EMAIL] Source file not found: {src_path}")
        return False

    # --- Compression threshold (10 MB) ---
    SMTP_CEILING = 10 * 1024 * 1024
    attach_path = src_path

    if src_path.stat().st_size > SMTP_CEILING:
        print(f"[EMAIL] File size exceeds 10 MB, compressing...")
        compressed = src_path.with_name(src_path.stem + "_compressed.mp4")
        
        result = subprocess.run([
            "ffmpeg", "-y", "-i", str(src_path),
            "-vcodec", "libx264", "-crf", "28",
            "-vf", "scale=1280:-2",
            "-acodec", "aac", "-b:a", "128k",
            str(compressed),
        ], capture_output=True, text=True)
        
        if result.returncode != 0:
            print(f"[EMAIL] Compression failed: {result.stderr}")
            return False
        
        if compressed.exists():
            attach_path = compressed

    # --- Parse himalaya SMTP credentials ---
    cfg_path = Path("/home/Hermes/.config/himalaya/config.toml")
    
    if not cfg_path.exists():
        print("[EMAIL] Himalaya config not found")
        return False

    email_addr = None
    smtp_pass = None
    
    for line in cfg_path.read_text().splitlines():
        line = line.strip()
        
        if line.startswith("email =") and email_addr is None:
            email_addr = line.split("=", 1)[1].strip().strip('"')
        
        if "auth.raw" in line and smtp_pass is None:
            smtp_pass = line.split("=", 1)[1].strip().strip('"')

    if not email_addr or not smtp_pass:
        print("[EMAIL] Failed to parse SMTP credentials from config")
        return False

    # --- Compose and send email ---
    msg = MIMEMultipart()
    msg["From"] = email_addr
    msg["To"] = "abhinavnehra2203@gmail.com"
    msg["Subject"] = f"{subject_context} | {src_path.name}"
    
    body = f"Video export completed.\n\nFile: {attach_path.name}\n"
    if dur_or_size:
        body += f"Details: {dur_or_size}\n"
    body += "\nGenerated by Hermes cron job."
    
    msg.attach(MIMEText(body, "plain"))

    with open(attach_path, "rb") as f:
        part = MIMEBase("application", "octet-stream")
        part.set_payload(f.read())
        encode_base64(part)
        part.add_header(
            "Content-Disposition",
            f"attachment; filename={attach_path.name}"
        )
        msg.attach(part)

    try:
        context = ssl.create_default_context()
        with smtplib.SMTP_SSL("smtp.gmail.com", 465, context=context) as server:
            server.login(email_addr, smtp_pass)
            server.sendmail(email_addr, "abhinavnehra2203@gmail.com", msg.as_string())
        print(f"[EMAIL] Sent successfully: {attach_path.name}")
        return True
    except Exception as e:
        print(f"[EMAIL] Send failed: {e}")
        return False

### Compression Settings

| Parameter | Value | Purpose |
|-----------|-------|---------|
| CRF | 28 | Quality balance (lower = better quality, larger file) |
| Scale | 1280:-2 | Width 1280px, height auto (divisible by 2) |
| Audio | AAC 128k | Standard quality, small size |

These settings typically reduce a 15 MB video to ~5-8 MB.

## Error Handling

| Error | Cause | Resolution |
|-------|-------|------------|
| `Source file not found` | Wrong path | Verify `file_path` argument |
| `Himalaya config not found` | Config missing | Run `himalaya account add` first |
| `Failed to parse SMTP credentials` | Malformed config | Ensure `email` and `auth.raw` fields exist |
| `Compression failed` | ffmpeg error | Check ffmpeg installation, inspect stderr |
| `Send failed` | SMTP error | Verify Gmail app password, check connectivity |
